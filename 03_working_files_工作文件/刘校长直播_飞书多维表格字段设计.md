# 刘校长直播飞书多维表格字段设计

## Base 名称

`刘校长直播运营工作台`

## 表 1：直播排期表

用途：所有直播从这里发起。

字段：

- 直播编号：自动编号
- 直播主题：文本
- 直播日期：日期时间
- 直播时长：单选，1小时 / 1.5小时 / 2小时
- 平台：多选，抖音 / 视频号 / 小红书 / 多平台
- 主播：人员，刘校长
- 运营负责人：人员
- 场控：人员
- 目标家长：单选，初三家长 / 高一家长 / 转轨家庭 / A-Level意向 / 低分转轨 / 其他
- 直播目标：多选，预约到校 / 留资 / 课程信任 / 升学答疑 / 招生转化
- 状态：单选，待选题 / 脚本中 / 待预热 / 待直播 / 已直播 / 已复盘
- 关联脚本：关联脚本生产表
- 关联物料：关联物料资产表
- 关联复盘：关联直播复盘表

## 表 2：选题库

用途：沉淀可反复优化的直播主题。

字段：

- 选题名称：文本
- 选题分类：单选，A-Level / 国际学校择校 / 中考后转轨 / 升学规划 / 师资课程 / 家长焦虑 / 奥斯翰优势
- 家长痛点：长文本
- 核心观点：长文本
- 是否适合刘校长：勾选
- 优先级：单选，高 / 中 / 低
- 适合平台：多选
- 复用次数：数字
- 最近使用日期：日期
- 数据表现：关联直播复盘表

## 表 3：脚本生产表

用途：管理每场直播脚本。

字段：

- 脚本编号：自动编号
- 关联直播：关联直播排期表
- 脚本状态：单选，待写 / 初稿 / 已审 / 已确认 / 已归档
- 直播标题：文本
- 开场 3 分钟：长文本
- 主体结构：长文本
- 核心案例：长文本
- 互动问题：长文本
- 转化话术：长文本
- 结尾 CTA：长文本
- 刘校长修改意见：长文本
- 最终脚本链接：附件/云文档

## 表 4：物料资产表

用途：管理封面、预热视频、贴片、二维码。

字段：

- 物料名称：文本
- 关联直播：关联直播排期表
- 物料类型：单选，直播封面 / 预热视频 / 海报 / 直播贴片 / 二维码 / 切片视频
- 负责人：人员
- 状态：单选，待做 / 制作中 / 待审 / 已确认 / 已发布
- 文件：附件
- 发布平台：多选
- 发布时间：日期时间
- 备注：长文本

## 表 5：直播执行表

用途：直播当天执行检查。

字段：

- 关联直播：关联直播排期表
- 开播检查：多选，设备 / 网络 / 声音 / 灯光 / 直播间标题 / 封面 / 预约链接 / 评论话术
- 实际开始时间：日期时间
- 实际结束时间：日期时间
- 直播状态：单选，准备中 / 直播中 / 已结束 / 异常
- 异常记录：长文本
- 场控记录：长文本
- 直播录屏：附件

## 表 6：评论问题库

用途：把直播评论变成选题库和顾问话术库。

字段：

- 问题原文：长文本
- 来源直播：关联直播排期表
- 问题分类：单选，课程 / 升学 / 费用 / 师资 / 住宿 / 安全 / 适合人群 / 到校咨询
- 家长意向：单选，高 / 中 / 低 / 不明确
- 标准回答：长文本
- 是否可做短视频：勾选
- 是否进入顾问跟进：勾选

## 表 7：线索跟进表

用途：承接直播来的家长线索。

字段：

- 家长姓名/昵称：文本
- 联系方式：电话
- 来源平台：单选，抖音 / 视频号 / 小红书 / 微信群 / 朋友圈
- 来源直播：关联直播排期表
- 孩子年级：单选，初一 / 初二 / 初三 / 高一 / 高二 / 高三 / 其他
- 意向课程：多选，A-Level / DSE / 韩国 / 日本 / 艺术 / 不确定
- 线索等级：单选，A / B / C / 待判断
- 负责顾问：人员
- 首次跟进时间：日期时间
- 跟进状态：单选，待联系 / 已联系 / 已预约 / 已到校 / 已报名 / 暂缓 / 无效
- 下一步动作：长文本
- 下次跟进时间：日期时间

## 表 8：直播复盘表

用途：判断选题和直播是否值得复用。

字段：

- 关联直播：关联直播排期表
- 观看人数：数字
- 峰值在线：数字
- 平均停留：数字
- 评论数：数字
- 私信数：数字
- 留资数：数字
- 有效线索数：数字
- 预约到校数：数字
- 直播评分：公式
- 表现最好片段：长文本
- 家长高频问题：长文本
- 下次优化建议：长文本
- 是否复播：勾选

## 自动化规则建议

1. 直播排期新增后，自动创建脚本、封面、预热、复盘任务。
2. 直播前 24 小时，自动提醒主播、运营、场控确认物料。
3. 直播状态改为“已结束”后，自动创建复盘记录和切片任务。
4. 线索等级为 A/B 时，自动提醒顾问 24 小时内跟进。
5. 跟进状态 3 天未更新时，自动提醒负责人。

# 刘校长直播 AI 工作流设计

更新时间：2026 年 5 月 15 日  
目标：把单人直播后台从“实时全能操作”改成“直播中轻记录，直播后 AI 整理”。

## 一、AI 工作流总原则

直播中不要让 AI 干扰开播。  
直播后让 AI 做整理、归类、复盘、导入和生成。

## 二、工作流总图

```text
直播中轻记录
  -> 本地记录器 CSV / 截图 / 录屏
  -> AI 整理
  -> 飞书多维表格
  -> 顾问跟进 / 切片任务 / 下场优化
```

## 三、直播中：AI 不实时介入

单人后台时，直播中 AI 不做复杂实时判断。原因：

- 你要优先保证直播不出问题。
- AI 需要素材输入，直播中来不及组织。
- 平台数据和评论不一定能自动接入。

直播中只做：

- 点按钮记录数据。
- 截图。
- 粘贴高意向评论。
- 标记关键词。
- 标记切片时间点。

## 四、直播后：AI 处理 6 类任务

### 1. 数据整理

输入：

- 单人直播记录器 CSV。
- 平台数据截图。

输出：

- `直播实时数据记录表` 可导入数据。
- `直播复盘表` 总结。

### 2. 评论问题归类

输入：

- 评论截图。
- 手动复制的评论文本。

输出：

- `评论问题库`：
  - 问题原文
  - 问题类型
  - 家长焦虑
  - 是否适合下场直播
  - 是否适合切片

### 3. 线索分级

输入：

- 关键词用户列表。
- 私信截图。
- 评论昵称和关键词。

输出：

- `线索跟进表`：
  - 家长昵称
  - 来源平台
  - 触发关键词
  - 线索等级 A/B/C
  - 建议跟进话术

### 4. 切片拆解

输入：

- 直播录屏。
- 切片时间点。
- 直播主题。

输出：

- `切片分发表`：
  - 切片标题
  - 来源时间点
  - 切片类型
  - 发布平台
  - 推荐文案

### 5. 顾问话术生成

输入：

- A/B/C 线索列表。

输出：

- 每类线索首联话术。
- 下次追访话术。
- 家长疑问解释话术。

### 6. 下一场优化

输入：

- 直播数据。
- 评论问题。
- 线索结果。
- 切片表现。

输出：

- 下场直播标题优化。
- 开场前 3 分钟优化。
- 互动问题优化。
- CTA 优化。

## 五、AI 指令模板

### 直播后复盘指令

```text
请根据我上传的直播数据 CSV、后台截图和评论截图，整理刘校长本场直播复盘。

输出格式：
1. 核心数据摘要
2. 数据变化时间线
3. 评论高频问题
4. A/B/C 线索初分级
5. 值得切片的 6 个片段
6. 下场直播优化建议
7. 可导入飞书的表格数据
```

### 评论归类指令

```text
请把以下直播评论按招生咨询价值分类：

分类：
- A类：到校/评估/明确课程咨询
- B类：路线/转轨/费用/管理/升学问题
- C类：资料/泛泛围观

请输出：
昵称、原评论、关键词、线索等级、建议回复、是否进入顾问跟进。
```

### 切片指令

```text
请根据以下直播打点和主题，生成 10 条切片选题。

要求：
- 每条 15-60 秒
- 标题适合抖音/视频号
- 区分信任型、问答型、转化型、知识型
- 标出建议开头文案
```

## 六、飞书导入方式

第一阶段：

- 本地记录器导出 CSV。
- 手动复制到飞书表格。
- AI 生成整理后的表格内容。

第二阶段：

- 用脚本读取 CSV。
- 调用飞书多维表格 API 写入。

第三阶段：

- 平台数据 API / 第三方工具 / RPA 自动入库。

## 七、为什么不直接全自动

目前限制：

- 抖音/视频号不一定开放完整实时评论和数据 API。
- 私信和留资涉及平台权限与合规。
- 招生线索需要人工判断，不能完全自动分级。
- 首场直播要先验证流程，再做自动化。

所以 6 月 1 日最稳方案是：

```text
直播中轻量采集 + 直播后 AI 整理 + 飞书沉淀
```

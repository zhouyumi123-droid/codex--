# 刘校长 6 月 1 日直播：顾问 A/B/C 线索分级话术

更新时间：2026 年 5 月 15 日  
目标：让直播产生的家长线索被快速分级、快速首联、快速进入下一步动作。

## 一、分级标准

### A 类线索：高意向

满足任意 2 条即可判断为 A 类：

- 主动打“到校”。
- 主动询问学费、入学、名额、考试、预约。
- 孩子处于初三/中考后/高一转轨关键期。
- 明确说想了解 A-Level / DSE / 国际高中。
- 愿意提供孩子年级、成绩、英语情况。
- 愿意加企微或预约电话。

处理时效：2 小时内首联。

### B 类线索：中意向

满足任意 1 条：

- 打“评估”“路线”“A-Level”“DSE”“转轨”。
- 有具体问题，但暂未提供完整信息。
- 想拿资料，但愿意说明孩子年级。
- 对国际路线有兴趣，但目标不明确。

处理时效：24 小时内首联。

### C 类线索：低意向/内容沉淀

特征：

- 只打“资料”。
- 只点赞关注，没有明确咨询。
- 问题泛泛，例如“多少钱”“在哪里”但不继续互动。
- 暂不愿提供孩子情况。

处理时效：进入资料包、粉丝群或后续内容触达。

## 二、A 类线索首联话术

### 电话/私信开场

```text
您好，我是奥斯翰国际学校招生顾问。您刚才在刘校长直播间留言想了解孩子路线/到校咨询，所以我第一时间联系您。

为了不耽误您时间，我先帮您做一个初步判断：孩子现在是几年级？目前成绩和英语大概是什么情况？
```

### 深挖问题

```text
您现在最纠结的是中考路径、国际课程选择，还是学校管理和升学出口？
```

```text
家庭目前有没有比较明确的目标地区，比如英国、香港、澳洲、新加坡，还是还在比较？
```

```text
孩子自己对国际路线是什么态度？是家长先了解，还是孩子也有意愿？
```

### 到校邀约

```text
您这个情况只靠线上几句话不太容易判断清楚。建议安排一次到校沟通，我们可以结合孩子年级、英语、成绩和目标方向，帮您看 A-Level / DSE / 其他路线哪个更适合。

您这周工作日晚上或周末哪个时间更方便？
```

## 三、B 类线索首联话术

### 私信开场

```text
您好，看到您在刘校长直播间关注国际路线评估。不同孩子适合的课程不一样，我先帮您做一个轻量判断。

请问孩子目前是初中还是高中？现在更关注 A-Level、DSE，还是整体国际高中路线？
```

### 发资料前筛选

```text
我可以先发您对应课程资料。为了避免发错方向，想确认一下：孩子目前几年级？英语基础大概怎么样？
```

### 推进到评估

```text
如果您愿意，我可以先帮您把孩子情况记录下来，做一次初步路线判断。判断完再决定要不要到校，不需要一开始就做决定。
```

## 四、C 类线索维护话术

```text
您好，这是奥斯翰国际学校国际高中方向资料。您可以先了解 A-Level、DSE 和其他升学方向。

如果后续想判断孩子适合哪条路线，可以再发孩子年级、英语和成绩情况，我帮您做初步判断。
```

后续触达节奏：

- 第 1 天：发送资料。
- 第 3 天：发送刘校直播切片。
- 第 7 天：发送“中考后转国际路线晚不晚”内容。
- 第 14 天：邀请看下一场直播或到校活动。

## 五、线索字段填写

顾问在飞书 `线索跟进表` 必填：

| 字段 | A 类 | B 类 | C 类 |
| --- | --- | --- | --- |
| 家长昵称 | 必填 | 必填 | 必填 |
| 来源平台 | 必填 | 必填 | 必填 |
| 来源直播 | 必填 | 必填 | 必填 |
| 触发关键词 | 必填 | 必填 | 必填 |
| 孩子年级 | 必填 | 尽量填写 | 可空 |
| 关注方向 | 必填 | 尽量填写 | 可空 |
| 线索等级 | A | B | C |
| 首联时间 | 必填 | 必填 | 可后置 |
| 下一步动作 | 到校/电话/评估 | 发资料/评估 | 内容沉淀 |

## 六、顾问反馈给直播团队

每场直播后，顾问必须反馈 4 类信息：

1. 家长最常问的问题。
2. 哪些话术带来高意向咨询。
3. 哪些家长没有继续回复，原因是什么。
4. 下一场直播最应该讲什么。

这些反馈写入：

- `评论问题库`
- `直播复盘表`
- `选题库`

## 七、禁止话术

- “一定能录取。”
- “保录某某学校。”
- “低分也能轻松进名校。”
- “不用努力也能出国。”
- “现在不报名就没有名额。”

招生顾问可以讲机会、路径、评估和规划，但不能做结果承诺。

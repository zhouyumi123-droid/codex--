# 刘校长 6 月 1 日直播：飞书实时数据记录表设计

更新时间：2026 年 5 月 15 日  
目标：让直播中每 15 分钟的数据、话题、动作和异常都能进入飞书，直播后可直接复盘。

## 一、表名

`直播实时数据记录表`

## 二、使用场景

直播过程中，数据场控每 15 分钟填写一行。  
如果出现明显波动，例如在线人数突然下降、评论突然增加、私信明显增加，也可以额外补一行。

## 三、字段设计

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 记录编号 | 文本 | 例如 `0601-DY-001` |
| 来源直播 | 文本 | 对应直播主题 |
| 平台 | 单选 | 抖音 / 视频号 / 小红书 / 其他 |
| 记录时间点 | 日期时间 | 实际记录时间 |
| 直播阶段 | 单选 | 开场 / 主体1 / 主体2 / Q&A / 转化 / 结束 |
| 当前话题 | 文本 | 刘校正在讲什么 |
| 当前在线 | 数字 | 当前同时在线人数 |
| 累计场观 | 数字 | 当前累计观看 |
| 最高在线 | 数字 | 如后台可见则填 |
| 平均停留秒数 | 数字 | 如后台可见则填 |
| 评论数 | 数字 | 当前累计评论 |
| 点赞数 | 数字 | 当前累计点赞 |
| 新增关注 | 数字 | 当前新增关注 |
| 私信数 | 数字 | 当前可见私信或咨询 |
| 关键词数量 | 数字 | 评论区出现“评估/路线/到校/资料”等数量 |
| 关键词明细 | 文本 | 例如：评估 6、路线 3、到校 1 |
| 主要问题 | 文本 | 当前家长最集中问什么 |
| 场控动作 | 文本 | 做了什么引导，例如让刘校重复 CTA |
| 刘校调整建议 | 文本 | 提醒刘校下一段怎么讲 |
| 异常情况 | 文本 | 卡顿、掉线、声音问题、违规风险等 |
| 是否生成复盘点 | 复选框 | 值得直播后重点复盘时勾选 |
| 是否生成切片 | 复选框 | 这一段值得剪视频时勾选 |
| 备注 | 文本 | 其他补充 |

## 四、6 月 1 日填写节奏

| 时间 | 动作 |
| --- | --- |
| 开播前 10 分钟 | 建好本场直播记录，确认平台、主题、人员 |
| 开播 0 分钟 | 记录初始数据和开场状态 |
| 开播 15 分钟 | 记录第一轮留人数据 |
| 开播 30 分钟 | 记录主体段表现 |
| 开播 45 分钟 | 记录互动与关键词 |
| 开播 60 分钟 | 记录转化动作和收尾 |
| 下播后 10 分钟 | 补总数据、截图、异常情况 |

## 五、场控填写规则

- 不追求字段全部实时填满，先保证：当前在线、累计场观、评论数、新增关注、关键词数量、主要问题、场控动作。
- 平台后台暂时看不到的字段，下播后再补。
- 每条记录只写一个时间点，不要把整场直播混在一行里。
- 如果某个话题明显带来评论或私信，要勾选 `是否生成切片`。
- 如果某个话题明显掉人，要勾选 `是否生成复盘点`，并写清原因判断。

## 六、直播后如何用这张表

直播后 24 小时内，把这张表和以下表联动使用：

| 来源 | 去向 | 动作 |
| --- | --- | --- |
| 关键词明细 | 线索跟进表 | 把高意向评论和私信录入线索 |
| 主要问题 | 评论问题库 | 整理成下一场 Q&A |
| 是否生成切片 | 切片分发表 | 生成切片任务 |
| 是否生成复盘点 | 直播复盘表 | 写入复盘结论 |
| 场控动作 | 自动化规则清单 | 判断是否需要新增自动化 |

## 七、后续自动化方向

第一阶段：人工每 15 分钟填写。  
第二阶段：直播后台数据导出后批量导入。  
第三阶段：通过平台 API / 第三方工具 / RPA 自动写入飞书。

6 月 1 日只要求第一阶段跑通。

# 金校直播首批选题库

## 选题原则
每场只解决一个家长真实决策问题。标题要像家长正在问的问题，不要像学校宣传口号。

|---:|---|---|
| 1 | 中考后转国际路线还来得及吗？金校长讲清楚3种选择 | 中考后焦虑家庭、9月入学 |
| 2 | A-Level、OSSD、AP、DSE到底怎么选？不同孩子别选错 | 课程路线咨询 |
| 3 | 英语一般的孩子，适不适合读国际课程？ | 英语弱但想转轨家庭 |

## 单场直播结构模板

### 0-3分钟：开场与留人
- 说明今天只解决一个问题。
- 抛出家长典型焦虑。
- 告诉观众听完能得到什么判断。
- 引导评论关键词。

### 3-15分钟：问题拆解
- 先讲家长常见误区。
- 再讲判断标准。
- 最后讲不同学生画像。

### 15-35分钟：路径解决
- 讲不同路线的优势。
- 讲不同路线的风险。
- 讲适合和不适合的学生。
- 穿插奥斯翰可承接的课程服务。

### 35-50分钟：评论诊断
- 挑选评论区具体问题。
- 后台记录孩子年级、成绩、目标国家、英语基础、是否考虑到校。
- 金校做方向判断，不在直播间做过度承诺。

### 50-60分钟：收口转化
- 总结今天的判断标准。
- 引导评论“评估”“资料”“到校”。
- 预告下一场主题。

## 首场建议主题
首场建议用：中考后转国际路线还来得及吗？金校长讲清楚3种选择。

原因：
- 时间点贴近今年9月前招生目标。
- 家长需求更急，容易形成咨询。
- 可以自然引出奥斯翰课程、入学评估、到校参观。
- 金校的课程理解和升学规划能力能充分发挥。

## 首场核心框架

### 1. 什么样的孩子适合现在考虑国际路线
- 不适应纯体制内竞争，但学习习惯不差。
- 有海外本科或多元升学想法。
- 家庭愿意接受语言、课程、升学规划同步推进。
- 孩子需要更明确的管理和路径设计。

### 2. 中考后常见三种选择
- 继续体制内高中，后续再考虑国际本科。
- 进入国际课程体系，提前准备海外升学。
- 选择日韩/港澳台/新加坡等更匹配家庭预算和孩子基础的方向。

### 3. 家长不要只看课程名字
同样叫国际课程，真正影响结果的是课程匹配、语言支持、过程管理、升学规划、学生自驱力和家庭配合。

### 4. 奥斯翰如何承接
奥斯翰可以提供国际课程、语言支持、升学规划和日常管理的组合式支持。具体路线需要结合孩子基础做评估，不建议直播间一刀切判断。

## 直播间关键词设计

| 关键词 | 后台动作 |
|---|---|
| 评估 | 引导填写孩子年级、成绩、英语基础、目标方向 |
| 资料 | 发送课程资料包 |
| 到校 | 邀约校园参观和升学面谈 |
| 中考 | 进入中考后转轨跟进链路 |
| 日韩 | 进入日韩方向跟进链路 |
| A-Level/OSSD/AP/DSE | 进入课程路线咨询链路 |

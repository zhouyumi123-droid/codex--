# 金校直播主播思维导图框架

## 中心主题
金校长国际课程规划直播间

核心目标：用金校的专业判断建立信任，用奥斯翰的课程服务承接转化。

## 1. 直播底层状态

### 1.1 呼吸感：干货与交流可以切换
金校不需要全程照稿讲。直播应该像一场家长咨询会：有主线、有判断、有互动，也允许根据评论临时展开。

#### 接流量：突然进人时怎么留人
当直播间突然进来一批新观众时，先不要继续讲很细的内容，应该短暂停顿并重新说明价值：

欢迎刚进来的家长，今天我们只讲一个问题：中考后如果不想只走普通高中路线，国际课程到底还来不来得及选。金校长会把几条路线的适合人群、风险和准备方式讲清楚，家长可以先听判断，再看孩子适不适合。

#### 拉流量：人数不动或掉人时怎么做数据
人数卡住时，不要机械要点赞，可以结合问题引导互动：

家里孩子今年初三或高一的家长，可以在评论区打个1，我看一下今天直播间主要是哪一类家庭。已经在看国际学校、国际课程的家长可以打2，我会按照你们的情况重点讲。

### 1.2 交流感：一对多直播，要讲成一对一咨询
金校要尽量看镜头，说话对象始终是“正在为孩子做选择的家长”。

可用互动句：
- 我刚刚讲的这个判断，家长能不能对上自己孩子的情况？能对上的打1。
- 如果孩子英语基础一般，但又想考虑国际路线，可以在评论区打“英语”，我后面单独讲。
- 你们现在最纠结的是课程、费用、升学还是孩子适不适合？可以直接打在评论区。
- 这个问题我不建议家长凭感觉决定，最好结合孩子基础评估。

### 1.3 参与感：每3-5分钟抛出一个问题
直播不是连续讲课，而是“问题 - 判断 - 解决 - 下一个问题”的循环。

每个小段都按这个结构：

1. 抛问题：家长是不是也遇到这个情况？
2. 给判断：这个问题不能只看表面，要看哪几个条件。
3. 讲路径：不同孩子分别怎么选。
4. 做互动：让家长打关键词或提问。
5. 引下段：解决这个问题后，下一个关键就是……

### 1.4 目标感：不断提醒本场直播解决什么
直播间随时有人新进来，因此每隔10-15分钟要重新说一次主题。

示例：

今天这场不是泛泛讲学校介绍，我们只解决一个问题：中考后家庭怎么判断孩子要不要转国际路线，以及怎么避免选错课程。

## 2. 金校人设表达

### 2.1 不要上来堆履历
履历要服务信任，不要变成自我介绍。

推荐表达：

我是奥斯翰国际部的金校长，这些年主要做国际课程体系建设和学生升学路径规划。今天我不替家长做决定，而是把不同路线适合什么孩子、不适合什么孩子讲清楚。

### 2.2 专业标签
- 国际部校长。
- 国际课程体系建设者。
- 海外升学路径规划专家。
- 熟悉英语、日语、韩语方向。
- 熟悉学生管理、语言学习、课程适配和升学规划。

### 2.3 金校直播的独特价值
金校不是只介绍学校，而是能回答家长最难判断的问题：

- 孩子到底适不适合国际路线？
- 英语一般能不能读？
- 哪些课程听起来好，但不适合某些孩子？
- 日韩、新加坡、港澳台、英美澳加方向怎么区分？
- 国际学校到底看什么，不只是看环境和学费？

## 3. 单场直播通用框架

### 3.1 开场3分钟
目标：讲清楚今天为什么值得听。

结构：

1. 欢迎家长。
2. 说明今天只讲一个主题。
3. 点出家长痛点。
4. 建立金校专业信任。
5. 引导评论关键词。

示例：

各位家长好，我是奥斯翰国际部金校长。今天这场直播，我们不做大而全的学校介绍，只讲一个很现实的问题：中考后如果家长开始考虑国际路线，到底还来不来得及，孩子适不适合，应该怎么选。  

如果孩子今年初三、高一，或者家长正在纠结普通高中和国际路线，可以在评论区打“中考”或“评估”，后台老师会根据孩子情况做记录。

### 3.2 主体30-40分钟
按“一个大主题拆成6个小问题”讲，每个问题3-5分钟。

通用小问题结构：

- 这个问题为什么重要？
- 家长常见误区是什么？
- 金校的判断标准是什么？
- 不同学生画像怎么处理？
- 奥斯翰能如何承接？
- 评论区做一次互动。

### 3.3 评论答疑10-15分钟
答疑不要散，要围绕本场主题筛问题。

优先回答：
- 有孩子年级和基础的问题。
- 明确问课程选择的问题。
- 明确问入学时间、学费、名额、到校的问题。

谨慎回答：
- “能不能保证录取？”
- “多久一定提分？”
- “这个孩子肯定能不能上？”

统一口径：

这个需要结合孩子目前基础、英语水平、学习状态和目标方向来判断，直播间我不能一刀切给结论。家长可以打“评估”，后台老师帮您约一次具体沟通。

### 3.4 收口5分钟
结构：

1. 总结本场判断标准。
2. 再次给出关键词。
3. 引导到校或一对一评估。
4. 预告下一场主题。

示例：

今天这场我们讲的是中考后转国际路线还来不来得及。家长记住，不是看别人读什么课程你就选什么课程，而是先看孩子基础、语言能力、目标国家、学习习惯和家庭规划。  

如果你想判断孩子适不适合，可以在评论区打“评估”；想看奥斯翰国际部课程资料，可以打“资料”；已经考虑今年入学的家长，可以打“到校”，后台老师帮您预约校园参观和面谈。

## 4. 首场直播思维导图

### 主题
中考后转国际路线还来得及吗？金校长讲清楚3种选择

### 4.1 开场问题
中考后家长最怕的不是没有选择，而是在焦虑里选错路线。

互动：

孩子今年初三的家长打1，高一高二的家长打2，已经在看国际学校的家长打3。

### 4.2 小问题1：哪些孩子适合现在考虑国际路线
判断维度：
- 体制内竞争压力是否明显。
- 孩子学习习惯是否还能调整。
- 英语或第二语言基础是否有培养空间。
- 家庭是否接受海外升学规划。
- 是否需要更明确的管理和路径设计。

互动：

如果你家孩子是“成绩中等但不想放弃升学”的情况，可以打“中等”，我后面会讲这种孩子怎么选。

### 4.3 小问题2：中考后常见3种选择
选择一：继续普通高中，后续再考虑国际本科。  
适合：目标明确、体制内适应度高、成绩仍有竞争力的学生。

选择二：进入国际课程体系，提前准备海外本科。  
适合：家庭目标明确、能接受语言和课程同步提升的学生。

选择三：选择日韩、港澳台、新加坡等更匹配的方向。  
适合：英语压力较大、预算和文化适配有特殊考虑、希望多元路径的家庭。

### 4.4 小问题3：家长最容易选错在哪里
误区：
- 只看课程名字。
- 只看学校环境。
- 只听别人家孩子的结果。
- 只问能不能录取，不看过程管理。
- 只看费用，不看路线适配。

互动：

家长现在最关心的是课程、学费、升学还是管理？可以直接打在评论区。

### 4.5 小问题4：英语一般怎么办
判断：
- 英语一般不是绝对不能读国际课程。
- 关键看孩子的学习习惯、语言提升周期、课程难度和目标国家。
- 不同路线对英语要求不同，不要一刀切。

承接：

这类孩子需要先做语言和课程适配评估，不能只凭“想出国”就定路线。

### 4.6 小问题5：奥斯翰怎么承接
表达重点：
- 奥斯翰不是让所有孩子走同一条路线。
- 学校会结合孩子基础、目标方向、语言能力、学习状态做规划。
- 国际课程、语言支持、升学规划和日常管理需要组合起来看。

### 4.7 收口
总结：

中考后不是不能转国际路线，但不能盲目转。先判断孩子，再判断路线，最后再判断学校。

关键词：
- 评估：做孩子路线判断。
- 资料：领取课程资料。
- 到校：预约校园参观和升学规划面谈。

## 5. 后台配合点

### 5.1 金校需要看到的提示
- 当前讲到哪一段。
- 下一个问题是什么。
- 哪些评论值得回答。
- 什么时候引导关键词。
- 什么时候收口。

### 5.2 后台不要打断金校的节奏
后台提示要短：

- 重新说主题。
- 引导评估。
- 回答英语问题。
- 插入奥斯翰承接。
- 准备收口。

### 5.3 评论优先级
优先给金校看的问题：

1. 有孩子年级。
2. 有成绩或英语基础。
3. 有目标方向。
4. 有入学时间。
5. 有到校意向。

## 6. 金校上播前速记版

金校只需要记住这六句话：

1. 我不是来替家长做决定，是帮家长把路线讲清楚。
2. 每场直播只解决一个核心问题。
3. 每3-5分钟抛一个家长问题。
4. 先讲判断标准，再讲奥斯翰方案。
5. 不承诺结果，只建议结合孩子基础评估。
6. 最后一定引导“评估、资料、到校”三个动作。

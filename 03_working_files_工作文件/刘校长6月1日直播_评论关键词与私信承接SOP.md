# 刘校长 6 月 1 日直播：评论关键词与私信承接 SOP

更新时间：2026 年 5 月 15 日  
目标：把直播间互动转成可跟进线索，同时降低违规和混乱风险。

## 一、承接原则

直播间只做轻承接：

- 引导评论关键词。
- 引导私信。
- 引导预约到校。
- 引导领取资料。

不在直播间高频展示站外联系方式，不做硬性倒流。高意向家长进入私信或企微后再由顾问承接。

## 二、关键词体系

| 关键词 | 意图判断 | 线索等级 | 后续动作 |
| --- | --- | --- | --- |
| 到校 | 明确到校意向 | A | 顾问 2 小时内联系 |
| 评估 | 想判断孩子适合度 | A/B | 收集年级、成绩、英语、目标方向 |
| 转轨 | 中考后或高一转路线 | A/B | 标记为转轨重点线索 |
| A-Level | 对课程有明确兴趣 | B | 发课程资料，邀约评估 |
| DSE | 对香港方向有兴趣 | B | 发 DSE 路线说明 |
| 路线 | 方向不清晰 | B/C | 做路线初筛 |
| 资料 | 低门槛资料领取 | C | 发资料，观察是否追问 |
| 费用 | 关注预算 | B/C | 私信询问年级和目标 |
| 管理 | 关注学校管理 | B | 发管理和升学规划说明 |

## 三、评论区话术

### 欢迎

```text
欢迎各位家长，今天刘校长会从校长视角讲：什么样的孩子适合读国际学校。可以先发一下孩子年级。
```

### 路线判断

```text
如果你正在纠结中考、高考和国际路线，可以在评论区打“路线”。
```

### 适合度评估

```text
想知道孩子适不适合国际课程，可以打“评估”，我们会根据年级、英语、成绩和目标方向做初步判断。
```

### 中考后转轨

```text
初三或中考后正在考虑国际路线的家长，可以打“转轨”，这类情况要尽快判断时间窗口。
```

### 到校咨询

```text
想预约到校详细了解课程和孩子适合度，可以打“到校”，顾问会一对一联系。
```

### 资料领取

```text
想要 A-Level / DSE / 国际高中资料，可以打“资料”。
```

## 四、私信第一轮回复

### 用户打“评估”

```text
您好，看到您想做孩子国际路线适合度评估。为了初步判断，请您发一下：
1. 孩子目前年级
2. 当前成绩大概区间
3. 英语基础
4. 家庭更倾向的方向：英国/澳洲/香港/新加坡/日韩/暂不确定
5. 是否考虑到校了解
```

### 用户打“到校”

```text
您好，已收到到校咨询需求。为了帮您安排更合适的老师，请您发一下孩子年级、当前学校/区域、想重点了解的课程方向，以及方便到校的时间段。
```

### 用户打“转轨”

```text
您好，中考后或初三转国际路线需要重点看时间窗口、英语基础和课程衔接。请您发一下孩子年级、目前成绩、英语情况，以及是否已经参加/准备中考。
```

### 用户打“A-Level”

```text
您好，A-Level 适合度主要看孩子的数学/英语基础、学科优势和目标国家。请您发一下孩子年级、数学英语情况，以及未来是否考虑英国、澳洲、香港或新加坡方向。
```

### 用户打“资料”

```text
您好，可以发您课程资料。为了发对应版本，请问孩子目前是初中还是高中？更想了解 A-Level、DSE、日韩方向，还是国际高中整体路线？
```

## 五、飞书录入规则

所有私信或评论线索录入 `线索跟进表`：

| 字段 | 填写要求 |
| --- | --- |
| 来源直播 | 6 月 1 日直播主题 |
| 来源平台 | 抖音 / 视频号 |
| 触发关键词 | 评估 / 到校 / 转轨 / A-Level / DSE / 资料 |
| 家长昵称 | 平台昵称 |
| 孩子年级 | 用户提供后补齐 |
| 关注方向 | A-Level / DSE / 日韩 / 综合择校 |
| 线索等级 | A/B/C |
| 跟进负责人 | 对应顾问 |
| 下次动作 | 首联 / 发资料 / 邀约到校 / 加企微 / 待观察 |

## 六、风险控制

- 不公开发送个人微信号、二维码、外链。
- 不承诺录取结果。
- 不承诺低分保录。
- 不在直播间直接比较攻击其他学校。
- 遇到敏感问题，引导私信详细沟通。

## 七、6 月 1 日最低执行标准

- 评论场控至少发 8 次引导话术。
- 至少记录 20 个有效评论问题。
- 所有打出关键词的用户都要进入飞书。
- A 类线索 2 小时内首联。
- B 类线索 24 小时内首联。

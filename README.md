# 奥斯翰国际学校项目

这个目录用于存放奥斯翰国际学校相关的 Codex IDE 工作文件。项目内资料、素材、工作稿和交付物分开保存，避免和其他项目混在一起。

## 目录结构

- `00_brief_项目简述/`：项目需求、招生方向、文案 brief、沟通记录。
- `01_source_materials_原始资料/`：用户提供的原始资料、旧版 PDF、Word、图片包等。
- `02_assets_视觉素材/`：可复用视觉素材，例如校徽、照片、二维码、图标、字体说明。
- `03_working_files_工作文件/`：设计和生成过程中的 HTML、Markdown、脚本、中间文件。
- `04_outputs_输出结果/`：Codex 生成的阶段性结果，例如预览图、草稿 PDF、排版版本。
- `05_exports_最终交付/`：最终交付文件，例如正式 PDF、DOCX、压缩包。
- `98_project_memory_上下文恢复/`：项目上下文、当前状态、断点记录和恢复入口。电脑或软件意外关闭后，优先读取这里。
- `99_archive_历史归档/`：过期版本、废弃尝试、备份。

说明：旧目录 `04_outputs/` 当前被系统进程锁定，暂时保留。后续新输出统一放入 `04_outputs_输出结果/`。

## 常用 skills

- `brochure-design-generation`：招生宣传册结构、版式方向、教育类宣传册设计。
- `pdf-design`：高级 PDF 页面设计、预览、迭代与打印输出。
- `canvas-design`：视觉稿、封面、海报式页面设计。
- `pdf`：PDF 拆解、检查、合并、导出等处理。
- `docx`：招生文案、说明文档、交付文档。

## 建议工作流

1. 把用户提供的原始文件放入 `01_source_materials_原始资料/`。
2. 把校徽、学校照片、二维码等可复用素材放入 `02_assets_视觉素材/`。
3. 在 `03_working_files_工作文件/` 中生成和编辑设计源文件。
4. 把每一轮预览稿放入 `04_outputs_输出结果/`。
5. 把确认后的最终版本放入 `05_exports_最终交付/`。

## 中断恢复

如果 Cursor、Codex、电脑或电源意外关闭，下次继续本项目时先读取：

`98_project_memory_上下文恢复/START_HERE_恢复上下文.md`

用户可直接说：

```text
继续奥斯翰项目，先读 98_project_memory_上下文恢复 里的恢复入口和当前状态。
```

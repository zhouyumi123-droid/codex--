## 文件结构

每所学校单独一个文件夹，文件夹内包含：

- 原始 PDF
- `SOURCE.md` 来源说明

部分第一轮尝试失败的链接会保留 `SOURCE.md` 但没有 PDF；正式可用清单以 `INDEX_设计参考总览.md` 和 `ALL_DOWNLOADED_FILES.md` 为准。

## 使用提醒

- 仅用于内部设计参考。
- 不直接复制原图、原文案或完整排版。
- 后续建议从 11 个 PDF 中筛选 3-5 个最贴近奥斯翰的，做 moodboard 和版式拆解。

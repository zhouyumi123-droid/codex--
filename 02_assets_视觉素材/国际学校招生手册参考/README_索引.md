## 使用建议

1. 做奥斯翰招生子公司汇报时，优先看 `13_Australian_International_School_Singapore`、`06_Ecolint_Geneva`、`10_Bangkok_Prep`，这三组最适合参考整体设计系统。
2. 做招生流程和服务承接页时，优先看 `08_Stamford_American_Singapore`、`03_KIST_Tokyo`、`04_UIA_International_School_of_Tokyo`。
3. 做费用预算、收费结构、ROI 表达时，优先看 `02_Fairview_International_School_UK`、`06_Ecolint_Geneva`、`11_Dulwich_College_Singapore`、`07_BCIS_Phuket`。
4. 做课程特色页时，优先看 `15_Bright_International_School`、`06_Ecolint_Geneva`、`13_Australian_International_School_Singapore`。
